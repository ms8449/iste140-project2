Glossary

Key AI terms

Artificial Intelligence (AI)
computer programs that can do human like thinking for basically everything
Machine Learning
a type of ai that learns from some rules or patterns
Neural Network
a system of small connected parts that pass information
Deep Learning
machine learning uses neural networks with a lot of layers
Training Data
data used to train ai such as images or text
Large Language Model (LLM)
an AI trained on a lot of text so it can understand it
Transformer
the type of network behind AI and chatbots
Token
thats a small piece of text like a word
Prompt
the question the user is asking the AI
Context Window
how much an ai can see or understand.If the conversation is too long it might start forgeting
Inference
when AI uses something it learned from you.This can be your name or school for example
Generative AI
AI that can create images or text
Hallucination
thats when an AI gives a wrong answear confidently
Bias
unfair opinions towards something or someone
Multimodal
an AI that can work with several inputs
Chatbot
a program where you talk to AI
Data Center
large and expensive building full of computers that power AI
Academic Integrity
being honest with your school,proffesor and yourself
